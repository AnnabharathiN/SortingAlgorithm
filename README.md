## Algorithms Implemented

### Bubble Sort
- Repeatedly compares adjacent elements and swaps them
  if they are in the wrong order
- Time complexity: O(n²)
- Best for: small datasets and learning purposes

### Selection Sort
- Finds the minimum element and places it at the beginning
- Repeats for the remaining unsorted portion
- Time complexity: O(n²)
- Best for: small datasets with minimal memory usage
